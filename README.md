One emoji for Drop Hunter, an AI agent that hunts crypto airdrops and builds software: 👻. The ghost is the agent's own mascot — silent, unseen, and relentless — it drifts through the chain unnoticed, snatches the drop, and is gone before anyone looks up. It reads instantly at any size, says exactly how the agent works, and stays far away from the obvious robot or smiley.

## Run it

```sh
python3 main.py
```

This writes exactly one character — 👻, no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), as a world-readable UTF-8 file.
